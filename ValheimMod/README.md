# ValheimMod

Replaces all loaded TextMeshPro font assets in place, updates TMP material presets that
still reference their old atlases, and applies the source `UnityEngine.Font` to legacy
Unity UI text. Replacement passes run when Jotunn GUI becomes available and whenever a
scene loads, so inactive prefabs and UI loaded by later scenes are covered as well.

## Runtime layout

Place the AssetBundle beside `ValheimMod.dll`:

```text
BepInEx/plugins/ValheimMod/
  ValheimMod.dll
  valheimmodassets
```

The bundle must contain the default `TMP_FontAsset` named in `FontManager.cs`. Other
bundled fonts can be selected independently in the mapping.

The bundle stays loaded for the lifetime of the mod because the replacement font assets
retain references to its textures, source font, fallbacks, shader, and material data.

## Font mapping

`FontManager.cs` contains two mappings:

- `TmpFontAssetMappings`: exact vanilla `TMP_FontAsset.name` to a replacement policy;
- `LegacyFontMappings`: exact vanilla `UnityEngine.Font.name` to a replacement policy.

Each entry can use one of three explicit policies:

- `FontMapping.UseDefault` uses `DefaultTmpReplacementAssetName` or
  `DefaultLegacyReplacementAssetName`;
- `FontMapping.KeepVanilla` leaves that exact game font unchanged;
- `FontMapping.FromBundle("Another SDF")` selects a named asset in `valheimmodassets`.

Every Valheim font observed in the current game version is listed separately. Change the
policy for any individual entry. Fonts introduced by future game updates use the default
replacement until an explicit entry is added. Valheim's original TMP fallback chains are
preserved, so a custom Latin/Cyrillic font can still reach language fonts marked
`KeepVanilla` for unsupported glyphs.

## Bundle deployment

The AssetBundle is built manually in Unity using **Assets > Build AssetBundles**. Building
the Visual Studio solution never starts or controls Unity; it only takes the existing
`Assets/AssetBundles/valheimmodassets` file. Visual Studio's Fast Up-to-date Check is disabled
for this project so F6 always runs deployment, even when only the bundle changed.

- Debug builds copy the DLL, symbols, and `valheimmodassets` to the configured BepInEx plugin
  directory.
- Release builds copy the DLL and `valheimmodassets` to `Package/plugins` before creating the
  Thunderstore ZIP.

## Building the AssetBundle

1. Open `ValheimModUnity` with the Unity version recorded in
   `ProjectSettings/ProjectVersion.txt`.
2. Import the desired `.ttf` or `.otf` file and create a TextMeshPro Font Asset from it.
3. Give the generated asset the name referenced by `FontManager.cs`.
4. For a static atlas, include every required Unicode character before generation. In
   particular, include the Cyrillic ranges needed by the localization; missing static
   glyphs cannot be generated by the runtime mod.
5. Assign the font asset to an AssetBundle named `valheimmodassets`.
6. Run **Assets > Build AssetBundles** manually after every font or bundle change.

The Debug and Release build pipelines copy the generated bundle to their destinations;
manual copying is not required.

## Crosshair

The `[Crosshair]` section in `ru.grigorijtomczuk.ValheimMod.cfg` controls the HUD
crosshair:

- `Enabled` enables the feature;
- `SpriteAssetName` selects a `Sprite` from `valheimmodassets`; an empty value keeps the
  vanilla sprite;
- `BowSpriteAssetName` optionally selects a separate bow sprite;
- `SizeMultiplier` changes the size relative to the vanilla HUD;
- `OverrideColor` and `Color` apply an HTML RGB color while preserving the visibility
  and alpha controlled by Valheim;
- `ApplyToBowCrosshair` controls whether the settings affect the bow crosshair.

To use a custom image, import it into Unity as **Sprite (2D and UI)**, assign it to the
`valheimmodassets` AssetBundle, build the bundle manually, and put its Unity object name in
`SpriteAssetName` or `BowSpriteAssetName`. No Harmony patch is used; the manager applies
the configured presentation after the vanilla HUD update.

The `[StealthIndicator]` section independently controls the stealth eye. Its
`SpriteAssetName` applies one sprite to every state; `HiddenSpriteAssetName`,
`TargetedSpriteAssetName`, and `AlertSpriteAssetName` can override individual states.
The section also has independent size and color settings.

Do not rename the custom asset to a vanilla font name. Replacement is performed in code
against the existing vanilla objects; Unity does not redirect serialized references by
matching asset names.

## Limitations

- The AssetBundle must be built with a Unity/TextMeshPro version compatible with the
  current Valheim client.
- A dynamic font asset is pre-populated at runtime with Basic Latin, Latin-1, Cyrillic,
  Cyrillic Supplement, General Punctuation, and the ruble sign. For other writing systems,
  generate a static font asset containing those glyphs or extend the configured ranges.
- Legacy `UnityEngine.UI.Text` and `TextMesh` components require the source `.ttf`/`.otf`
  to remain referenced by the bundled `TMP_FontAsset`.
